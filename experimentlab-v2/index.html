METHODOLOGY

Assumptions are part of the product.

Binary

Difference in proportions, relative lift, normal-theory CI and two-sided normal approximation.

Continuous / revenue

Difference in means on the original metric scale using a Welch-style normal approximation.

Bootstrap

Independent within-arm resampling and percentile 95% interval as a sensitivity analysis.

CUPED

Pre-treatment covariate adjustment intended to reduce variance when measured before treatment.

DiD

Requires parallel trends, consistent treatment timing and no differential concurrent shocks.

Staggered DiD

Varying treatment timing requires cohort/event-time estimators; the current module is a design diagnostic.

Synthetic control

Needs a credible donor pool, treated unit, pre-period fit and placebo diagnostics.

TMLE

Requires a defined estimand, nuisance models, positivity, consistency and robust uncertainty such as cross-fitting and influence curves.
