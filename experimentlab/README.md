# ExperimentLab

An independent browser-based experimentation workbench by Ayan Ghosh.

## Demonstrates
- Experiment health / allocation checks
- Treatment effect estimation
- Confidence intervals and p-values
- CUPED-style adjustment
- Exploratory segment analysis
- Transparent decision support

## Input
Required: treatment (0/1), conversion (0/1)
Optional: pre_metric, country

All analysis runs locally in the browser.
