03 · CAUSAL BUSINESS IMPACT

Better answers only matter if customers behave differently.

The offline evaluation establishes model quality. The product experiment establishes whether that quality change creates incremental customer and business outcomes. The simulated AI assistant was rolled out by geography on different dates. The platform makes the identification strategy visible instead of assuming a simple before/after comparison is causal.

07 · METHODOLOGY & PRODUCTION PATH

The technical boundary matters.

GenAI product + trace

FastAPI service, retrieval layer, vector index, prompt/version registry, structured traces, token accounting, response citations and model/tool metadata.

LLM evaluation

Pointwise and pairwise evaluation, judge calibration against human labels, bootstrap confidence intervals, disagreement analysis and evaluation-set versioning.

Experimentation

Randomized A/B where feasible; paired bootstrap for offline prompt comparisons; CUPED only when a pre-treatment covariate is appropriate for variance reduction.

Causal identification

Staggered DiD / event studies for rollout timing, synthetic control for suitable aggregate interventions, and explicit pre-trend / overlap diagnostics.

Causal ML

Out-of-sample CATE / uplift models with policy-value evaluation, uplift curves and segment-level diagnostics rather than treating treatment-effect prediction as ordinary supervised learning.

Decision layer

Convert τ(X), customer contribution, AI cost, capacity, latency and risk constraints into a routing policy. The final artifact is an auditable decision, not only a model score.

Production boundary: application traces feed the evaluation contract; validated quality changes enter product experiments; causal estimates feed economics; economics and constraints feed rollout policy. What is synthetic: the product traces, experiment data, causal estimates and economics shown here are deterministic portfolio data. The architecture and analysis contracts are designed so the same pipeline can consume real application traces and experimental data without changing the conceptual layers.
